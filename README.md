# 代码中注释采用了Code Tag（Clion设置中的TODO配置），以下为相关规定
### 📖 详细用法与代码示例

#### 1. `TODO` (To Do - 待办事项)
*   **用法**：表示这里还需要做些什么，但暂时不影响当前编译或基本运行。通常用于新功能的占位，或已知的性能优化点。
*   **示例**：
    ```c
    // TODO: 这里后续需要加上异常处理，防止传感器断连导致死循环
    float theta_dot = BMI088.Get_Gyro_Y(); 
    
    // TODO: 目前是单线程处理，后续数据量大了需要换成多线程
    process_data();
    ```

#### 2. `FIXME` (Fix Me - 待修复)
*   **用法**：比 `TODO` 更紧急。表示这里的代码是**错的**，或者在某些边界条件下会出严重问题，必须尽快修复。
*   **示例**：
    ```c
    // FIXME: 下面的除法没有判断分母是否为0，导致过零点时程序崩溃
    float result = a / b; 
    
    // FIXME: 这里的数组越界了，可能会篡改其他变量内存
    for(int i=0; i<=10; i++) { arr[i] = 0; }
    ```

#### 3. `XXX` (Warning - 警告/隐患)
*   **用法**：表示代码本身可能能跑，但实现方式很危险、很糟糕，或者存在严重的隐患。通常用来提醒别人“别碰这段代码，或者碰之前先找我”。
*   **示例**：
    ```c
    // XXX: 这里直接操作了硬件寄存器，如果并发访问可能会引发竞态条件
    *pReg |= 0x01; 
    
    // XXX: 这段代码写得太烂了，但暂时没时间重构，千万别在这基础上加功能
    ```

#### 4. `HACK` (临时黑科技)
*   **用法**：表示这是一种不优雅、非常规的临时解决方案。通常是为了赶进度，或者绕开第三方库的 Bug。
*   **示例**：
    ```c
    // HACK: 硬件设计有缺陷，必须在这里延时 10ms 才能读到正确的 I2C 数据，不要删！
    delay_ms(10);
    
    // HACK: 强制将指针转为int来比较地址，这是个临时方案，等底层库更新了要改掉
    ```
